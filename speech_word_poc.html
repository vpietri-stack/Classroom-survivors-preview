Single-word speech lab

Record once. Compare what each approach hears from the same recording. This page does not upload audio, save learning progress or change the live app.

1. Choose what to test

Whisper reuses the app’s cached ~41 MB model. Moonshine needs about 32 MB of additional model and tokenizer files the first time; its browser runtime may also need downloading. Both run on this device. Models run in sequence to limit memory use.

Try a clear reading, a similar wrong word, and silence. For example: expect bored, but deliberately say bird.

2. Make one recording

Ready. Tap Record, speak, then tap Stop.

A new recording clears the previous result. Changing the target requires another comparison. Recordings and results are kept only while this page is open; download them if you want to keep them.

3. Compare results

Transcript match asks whether the written recognition matches your target. Target-aware hint is the current Whisper checker’s green/neutral decision. Neither is a pronunciation grade. Moonshine currently supplies a transcript comparison only.

Completed results can be downloaded while checking continues, and are kept if you stop or skip Moonshine. The export includes the target, your judgement, transcripts, decisions and timings, but no audio. Download the recording separately so it can be replayed later. Word-check thresholds are unchanged: this experiment gathers evidence before we tune them.
